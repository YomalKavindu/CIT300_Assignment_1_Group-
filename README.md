# CIT300_Assignment_1_Group-
University Student Record and Campus Route Management System
CIT300 - Data Structures and Algorithms
Graded Practical Assignment 1


project overview

this project is a java based console application designed to manage university student records and represent the campus route network. The application demonstrates the practical implementation of fundamental linear and non-linear data structures, searching techniques, and graph traversal algorithms.

include;
singly linked list : Dynamic storage and management of student records.
stack  : History tracking and action log for recent operations and deletions.
Queue : First-In, First-Out (FIFO) processing for student service requests.
Binary search tree : In-order traversal and sorted display of student records by Student ID.
hash table : Direct $O(1)$ search lookup using hashing with separate chaining.
graph : Adjacency list representation of campus locations and path connections with BFS and DFS traversals.
